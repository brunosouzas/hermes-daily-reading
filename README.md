# hermes-daily-reading

A daily reading digest for [Hermes Agent](https://github.com/NousResearch/hermes-agent). It reads your RSS and Atom feeds, removes duplicates across them and ranks the items by your themes. Then it writes a short summary in your language, reads it aloud with the TTS voice you use in Hermes, and lists the day's items on a Hermes Desktop page. From that page you can mark an item read, save it as a note fragment, or turn it into an article idea.

Status: in design. The specification is in [`openspec/`](openspec/). Nothing is released yet.
